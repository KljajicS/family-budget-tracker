# Milestone 2: Budgets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Monthly budget per category with pace tracking: a Budgets tab (totals, per-category bars, edit screen), a Budgets section on Home showing the three closest to running out, and the budget reserve wired into safe to spend.

**Architecture:** `BudgetSet` is a new event; the projector keeps a `budget` read table keyed by category and month. Pure `BudgetCalculator` in `domain` turns budget plus spent into a status. Repository exposes effective budgets for a month (stored for that month, else the latest earlier month, so amounts copy forward without writing events). Two new screens under `ui/budgets`, one shared `PaceBar` composable in `ui/theme`.

**Tech Stack:** Same as milestone 1. No new dependencies.

**Spec:** `docs/specs/2026-10-14-family-budget-design.md` sections 4, 5, 6.1. ADR 7. Mockup `docs/design/budgets-light.png`, tokens in `docs/design/tokens.md`.

**Revision 2026-10-14, after the first device test:** the bulk "edit all categories" screen in Task 3 was replaced. Budgets are created one at a time with a form (category, amount, currency), rows open the same form for editing, and the form has Delete. Repository API is `setBudget(Budget)` and `removeBudget(categoryId, month)` with a new `BudgetRemoved` event; the first write in a month pins the carried-forward set so a delete cannot be undone by carry-forward. Each budget keeps its own currency; spending is converted into it, and totals and the reserve are converted to RSD where a rate exists. The code is the source of truth where this document and the code differ.

## Global Constraints

- All milestone 1 constraints hold: `rs.budget.domain` has no Android imports, money is `Money`, strings in both `strings.xml` files, no em or en dashes, commits in imperative mood without attribution.
- Month is `java.time.YearMonth`, stored as the string `yyyy-MM`.
- Budget amounts are RSD only in this milestone (spending is compared after conversion with the RSD-only `Rates`, same as Home).
- Pace rule (decided 2026-10-14): `pace = dayOfMonth / daysInMonth`. Status is `OVER` when spent > budget, `LOW` when left < 10% of budget, `AHEAD` when spent ÷ budget ≤ pace, `ON_TRACK` when spent ÷ budget ≤ pace + 0.10, else `OVER_PACE`.
- Home shows the three budgets with the highest spent ÷ budget ratio (decided 2026-10-14).
- Validation before every commit: `./gradlew :app:testDebugUnitTest :app:lintDebug :app:checkDomainPurity :app:assembleDebug` (or `make check` inside toolbox `dev`).

## Review Focus

1. A category with a budget of 0 or no budget: no division by zero, it is simply not listed (Task 1 test).
2. Transactions dated in another month must not count toward this month's spent (Task 1 test).
3. First month after setup: no budgets anywhere, Budgets tab shows the empty hint and Edit still works (Task 2 test, Task 3 UI).
4. Editing in November when only October budgets exist: edit screen pre-fills October amounts and saving writes November events, October untouched (Task 2 test).
5. Safe to spend must drop by the sum of `max(0, budget − spent)` and never go up when budgets are added (Task 2 test).

`app/src/main/kotlin/rs/budget/domain/BudgetCalculator.kt`:

```kotlin
package rs.budget.domain

import java.math.BigDecimal
import java.math.RoundingMode
import java.time.LocalDate
import java.time.YearMonth

enum class PaceState { AHEAD, ON_TRACK, OVER_PACE, LOW, OVER }

data class BudgetStatus(
    val categoryId: String,
    val budget: Money,
    val spent: Money,
    val left: Money,
    val ratio: Double,
    val pace: Double,
    val state: PaceState,
)

object BudgetCalculator {

    /** One status per budget with a positive amount, sorted by spent ÷ budget descending. Amounts not convertible to RSD are skipped. */
    fun statuses(today: LocalDate, budgets: List<Budget>, transactions: List<Transaction>, rates: Rates): List<BudgetStatus> {
        val month = YearMonth.from(today)
        val pace = today.dayOfMonth.toDouble() / month.lengthOfMonth()
        val spentByCategory = transactions
            .filter { it.type == TransactionType.EXPENSE && it.categoryId != null && YearMonth.from(it.date) == month }
            .groupBy { it.categoryId!! }
            .mapValues { (_, txs) -> txs.fold(Money.zero(Currency.RSD)) { acc, t -> acc + (rates.convert(t.money) ?: Money.zero(Currency.RSD)) } }

        return budgets
            .filter { it.month == month && it.money.amount.signum() > 0 }
            .map { b ->
                val budget = rates.convert(b.money) ?: Money.zero(Currency.RSD)
                val spent = spentByCategory[b.categoryId] ?: Money.zero(Currency.RSD)
                val left = budget - spent
                val ratio = spent.amount.divide(budget.amount, 4, RoundingMode.HALF_UP).toDouble()
                val state = when {
                    left.isNegative -> PaceState.OVER
                    left.amount < budget.amount.multiply(BigDecimal("0.10")) -> PaceState.LOW
                    ratio <= pace -> PaceState.AHEAD
                    ratio <= pace + 0.10 -> PaceState.ON_TRACK
                    else -> PaceState.OVER_PACE
                }
                BudgetStatus(b.categoryId, budget, spent, left, ratio, pace, state)
            }
            .sortedByDescending { it.ratio }
    }

    /** Money the budgets still claim this month. Overspent categories contribute nothing. */
    fun reserve(statuses: List<BudgetStatus>): Money =
        statuses.fold(Money.zero(Currency.RSD)) { acc, s -> if (s.left.isNegative) acc else acc + s.left }

    /** Total spent and total budgeted across all statuses. */
    fun total(statuses: List<BudgetStatus>): Pair<Money, Money> =
        statuses.fold(Money.zero(Currency.RSD)) { a, s -> a + s.spent } to statuses.fold(Money.zero(Currency.RSD)) { a, s -> a + s.budget }
}
```

```kotlin
    val daysLeft: Int,
    val statuses: List<BudgetStatus>,
    val spent: Money,
    val total: Money,
    val categories: List<Category>,

    val state: StateFlow<BudgetsState?> = combine(repo.budgetStatuses, repo.categories) { statuses, categories ->

        val month = YearMonth.from(today)
        val (spent, total) = BudgetCalculator.total(statuses)
        BudgetsState(month, month.lengthOfMonth() - today.dayOfMonth + 1, statuses, spent, total, categories)
    }.stateIn(viewModelScope, SharingStarted.WhileSubscribed(5_000), null)
}

data class EditRow(val category: Category, val amountText: String)
data class EditState(val rows: List<EditRow> = emptyList(), val saved: Boolean = false)

@HiltViewModel
class EditBudgetsViewModel @Inject constructor(private val repo: BudgetRepository, private val clock: Clock) : ViewModel() {
    private val month = YearMonth.from(clock.today())
    private val _state = MutableStateFlow(EditState())
    val state: StateFlow<EditState> = _state

    init {
        viewModelScope.launch {
            val categories = repo.categories.first().sortedBy { c -> StarterCategories.all.indexOfFirst { it.id == c.id }.let { if (it < 0) Int.MAX_VALUE else it } }
            val current = repo.effectiveBudgets(month).first().associateBy { it.categoryId }
            _state.update { s ->
                s.copy(rows = categories.map { c -> EditRow(c, current[c.id]?.money?.amount?.stripTrailingZeros()?.toPlainString() ?: "") })
            }
        }
    }

    fun setAmount(categoryId: String, text: String) {
        if (text.isNotEmpty() && text.toBigDecimalOrNull() == null) return
        _state.update { s -> s.copy(rows = s.rows.map { if (it.category.id == categoryId) it.copy(amountText = text) else it }) }
    }

    fun save() {
        val amounts = _state.value.rows
            .mapNotNull { r -> r.amountText.toBigDecimalOrNull()?.let { r.category.id to Money.of(it, Currency.RSD) } }
            .toMap()
        viewModelScope.launch {
            repo.setBudgets(month, amounts)
            _state.update { it.copy(saved = true) }
        }
    }
}
```

Note: an emptied field saves nothing for that category, so a carried-forward amount stays. Writing an explicit zero (`0`) clears it, because the calculator skips zero budgets.

```kotlin
fun BudgetRow(st: BudgetStatus, categories: List<Category>, compact: Boolean = false) {

    val category = categories.firstOrNull { it.id == st.categoryId }

    val warn = st.state == PaceState.LOW || st.state == PaceState.OVER || st.state == PaceState.OVER_PACE
    val barColor = if (st.state == PaceState.LOW || st.state == PaceState.OVER) c.orange else color
    val hint = when (st.state) {
        PaceState.AHEAD -> stringResource(R.string.budgets_row_left, formatAmount(st.left)) + " · " + stringResource(R.string.budgets_ahead)
        PaceState.ON_TRACK -> stringResource(R.string.budgets_row_left, formatAmount(st.left)) + " · " + stringResource(R.string.budgets_on_track)
        PaceState.OVER_PACE -> stringResource(R.string.budgets_row_left, formatAmount(st.left)) + " · " + stringResource(R.string.budgets_over_pace)
        PaceState.LOW -> stringResource(R.string.budgets_low, formatAmount(st.left))
        PaceState.OVER -> stringResource(R.string.budgets_over, formatAmount(-st.left))
    }
    Column(verticalArrangement = Arrangement.spacedBy(if (compact) 6.dp else 7.dp)) {
        Row(verticalAlignment = Alignment.CenterVertically, horizontalArrangement = Arrangement.spacedBy(10.dp)) {

        if (!compact) Text(hint, style = CaptionStyle, color = if (warn) c.orange else c.muted)
    }
```
